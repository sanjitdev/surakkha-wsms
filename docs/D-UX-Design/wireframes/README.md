# wireframes/

WDS-spec folder for page wireframes.

Per WDS `agents/wireframe.md`:

> Excalidraw wireframe saved to `D-UX-Design/wireframes/[page-slug].excalidraw`
> PNG export at `D-UX-Design/wireframes/[page-slug].png`

This folder is the future home for `.excalidraw` + `.png` exports — one pair per page.

Currently empty. Prior `wireframes/*.md` "mirror" files (navigation copies of the spec) were removed in the 2026-09-15 convention cleanup. The source of truth for any page is its spec file in the parent `D-UX-Design/` folder (e.g. `../operator-dashboard.md`).
