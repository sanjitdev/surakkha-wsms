Choice — which token set wins?

The choice cascades into Scenarios 03, 04, 05 (all written against Phase 4 semantics), the 3 Tier 1 specs, and the data contract for Phase 2 PHA dashboard. Tell Freya which one to lock and the rest of the cascade is mechanical.

Option A — Accept lockdown (recommended)

Token names --color-trust-t1/2/3 stay. The lockdown hex values bind. Scenarios 03 / 04 / 05 get re-read; the "anchor-priority" framing becomes a separate reporter-badge dimension, not a trust-band tier.

Pros: preserves 18 lockdown files' work; the structural data model matches the bmad design intent; Scenarios 04's hotline-sourced incidents render as neutral T1 + hotline reporter-badge (cleaner separation).

Cons: ~3–4 hours of scenario/spec editing; the data contract (Scenario 05) needs Shape 4 (reporter cohort retention) updated to use the reporter-badge dimension.

Option B — Rename Phase 4 tokens to a new namespace

Phase 4's --color-trust-t1/2/3 get renamed to --color-tier-anchor-priority / verified / hotline so they coexist with the lockdown tokens. Both systems ship side-by-side.

Pros: explicit separation; no ambiguity in either spec.

Cons: doubles the trust-band token surface; forces a "which palette am I in?" decision on every page; the team has to learn two tier systems; future contributors will be confused.
