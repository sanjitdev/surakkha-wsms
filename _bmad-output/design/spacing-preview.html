4 · Buttons

Four styles (primary / secondary / ghost / danger-outline). Three sizes (sm 28 / md 36 / lg 44). Icon+text uses 8 px gap (--space-sm). Icon-only buttons are square. Danger uses outline + tinted-bg hover (dim 1 §7.3 — no filled danger).

One size (md, 36 px). Text input and search input (with leading icon). Focus state: brand-400 border + 2 px brand-200 ring. Bangla placeholder renders in Noto Sans Bengali (dim 2 §9.4).
