Data Visualization / Charts

Dim 5b · LOCKED contract — 2026-09-07 · 9 chart types · 33 new tokens · Recharts + Leaflet · Priya desktop + mobile + print + real-time.

1 · Scope & library

This dimension locks the chart primitive that composes dim-1-4 tokens into time-series, categorical, and geographic visualizations. Recharts is the rendering library (~95 KB gzip, declarative, SVG-based, themable via CSS custom properties). Leaflet + leaflet.markercluster powers the simple map view (chart type #9).

9 chart types ship: time-series line, vertical bar, horizontal bar, donut, sparkline, stacked area, stacked bar, heatmap, sensor map. All 9 are demonstrated below as inline SVG mocks. The actual Recharts + Leaflet integration in surakkha-app/ is owned by the engineering-setup workstream — dim 5b ships the contract, not the wiring.

10 · Real-time mode state machine

Dim 5b §10 · 3 modes: static (default), poll (30s ±10% jitter), live-sse (EventSource). SSE drops auto-fallback to poll.

mode: 'static'

No fetcher. Data is immutable. Default for all embedded KPI sparklines and historical views.

STATIC

mode: 'poll'

Triggers onRefresh every refreshIntervalMs with ±10% jitter (default 30s). Consumer refetches via React Query / SWR.

POLLING · 30s

mode: 'live-sse'

Opens EventSource('/api/sensors/stream'). Exponential backoff 3s/6s/12s/30s cap. After 2 failed reconnects, falls back to poll + emits onConnectionLost.
