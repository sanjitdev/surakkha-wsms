Surakkha v1 — Iconography

Lucide icon set, inline SVG, currentColor. Five size tokens, three stroke weights, three semantic positions. Toggle theme + locale to verify Bangla/Latin split and dark-mode contrast.

1 · Icon Size Scale

Five size tokens. Stroke weight auto-scales: 1.5px on xs/sm, 2px on md, 2.5px on lg/xl. This is the optical-balance fix for the Lucide 24px-grid + 2px-stroke default.

Sample icons left-to-right: alert-triangle · map-pin · target · chevron-down · search. All paths from Lucide v0.460.0 (MIT).

2 · Stroke Weight — Optical Balance

Same Lucide icon at three stroke widths, rendered at sm (14px). 2px stroke at sm reads as chunky/heavy; 1px stroke reads as thin/broken; 1.5px is the optical balance point.
