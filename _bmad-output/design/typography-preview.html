Surakkha v1 — Typography

Locked font system across all four surfaces. Toggle theme and locale in the top-right. Tabular numerals, VS15-glyph consumer messaging, Bangla-specific line-heights.

3 · Per-family Line Height

Latin body uses line-height 1.5. Bangla body uses line-height 1.6 (Bangla glyphs sit higher in the x-height than Latin and need room above their ascenders).

5 · Tabular Numerals

Operator data displays must use font-variant-numeric: tabular-nums so columns of figures line up. Without it, digits drift in width and columns look ragged.

6 · Consumer Messages (Ramesh-channel)

Six message shapes, both locales. Glyphs forced monochrome via U+FE0E (VS15). ≤ 64 chars per line. Footer is — {ISSUING_AUTHORITY} ({VERIFICATION_HORIZON}).
