§3.2 · Easing tokens

3 easings only. --ease-out for state-gain (default), --ease-in for state-loss, --ease-in-out for symmetric state-change. No spring physics, no overshoot, no bounce — civic-steady.

--ease-out

cubic-bezier(0.2, 0.8, 0.4, 1)
Default for 80% of motion. Opening, appearing, gaining attention. Press, ack-pulse, new-data flash, modal enter.

--ease-in

cubic-bezier(0.6, 0, 0.8, 0.2)
State-loss. Closing, dismissing, deprecating. Modal exit (120ms).

--ease-in-out

cubic-bezier(0.4, 0, 0.6, 1)
Symmetric. Theme switch, SSE heartbeat dot, chain-fail shake.
