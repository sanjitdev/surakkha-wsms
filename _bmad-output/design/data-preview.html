Data Formats

Dim 6 · LOCKED contract — 2026-09-07 · TS-first with JSON + Zod examples · 8 component shapes · 6 page-template shapes · 8 empty-state specs · 6 domain entities.

1 · Scope

Component data shapes — what each component receives via props. Covers all 8 dim-4 components, 6 dim-5 page templates, 8 dim-5 empty states, 1 dim-5 audit-log row, plus 6 domain entities (User, Sensor, SensorReading, AnjaliReport, Cluster, ChainRef).

Backend wire format (sensor envelopes, signature formats) is deferred to dim 7. State management (Redux/Zustand/React Query) is engineering-setup territory.

2 · Format Conventions

TS-first; JSON example; optional Zod schema. Branded IDs. ISO 8601 timestamps. Locale at container, not per-string.

Branded IDs
Domain IDs are branded strings, preventing accidental cross-domain passing (SensorId is not assignable to IncidentId).
type SensorId   = string & { readonly __brand: 'SensorId' };
type IncidentId = string & { readonly __brand: 'IncidentId' };
type WardId     = string & { readonly __brand: 'WardId' };
type ClusterId  = string & { readonly __brand: 'ClusterId' };
ISO 8601 Timestamps
Branded string, not Date object. JSON-serialisable; locale-independent at storage; presentation converts to local time.
type ISOTimestamp =
  string & { readonly __brand: 'ISOTimestamp' };

// Example: 2026-09-07T09:21:14.000Z
const t: ISOTimestamp = '2026-09-07T09:21:14Z';

3 · Locale at Container (not per-string)

Per dim-4 §15 + dim-5 §10.2: <body data-locale="bn"> flips font for the entire subtree. Bangla content is plain text in data — never { text, locale }.

data-locale="en" — Plex Sans
{
  "id": "anjali.p",
  "message": "Brown water since morning",
  "ward": "ward-04"
}

Renders "Brown water since morning" in IBM Plex Sans.

data-locale="bn" — Noto Sans Bengali
{
  "id": "anjali.p",
  "message": "সকাল থেকে পানি বাদামি",
  "ward": "ward-04"
}

Renders "সকাল থেকে পানি বাদামি" in Noto Sans Bengali.

Same data shape, two rendering styles. The data layer carries the message string verbatim; the rendering layer (driven by data-locale) chooses the font.

8 · What is NOT in Data

Per dim-4 §19 + dim-5 §14. If a shape needs any of these for rendering, that's a dim-6 violation — fix the tokens, not the data.

⛔ Banned in data:
  • Spacing values { padding: 16 }
  • Color values { bg: '#F7F7F5' }
  • Breakpoint values { responsive: '>768px' }
  • Z-index values { z: 100 }
  • Animation durations { transition: 150 }
  • Shadow values { shadow: '...' }
  • Per-string locale tags { text, locale }
  • Font-family declarations
  • any in component prop types
  • Date objects (use ISO 8601 strings)

Ban vs OK — examples

Closed-set values

⛔ Ban
{
  "variant": "primary", // could be anything
  "size": "medium",   // string erases enum
  "band": "hiiii"     // typo!
}
✓ OK
{
  "variant": "primary",
  "size": "md",
  "band": "high"     // discriminated union
}

Per-string locale

⛔ Ban — { text, locale } pairs
{
  "title": {
    "text": "অঞ্জলি · পানিতে গন্ধ",
    "locale": "bn"
  }
}

// 2× payload size;
// per-string ambiguity;
// banned per dim-4 §15.
✓ OK — plain string at container locale
{
  "title": "অঞ্জলি · পানিতে গন্ধ"
}

// renders Bengali when
// <body data-locale="bn">,
// Latin otherwise.

Timestamps

⛔ Ban — Date objects
{
  "timestamp": new Date(1725694874000),
  "by": new Date()
}

// not JSON-serialisable
// locale-dependent
// strftime vs ISO confusion
✓ OK — ISO 8601 branded strings
{
  "timestamp": "2026-09-07T09:21:14Z",
  "expiresAt": "2026-12-31T23:59:59Z"
}

// JSON-serialisable
// locale-independent
// one canonical format

Numeric values for Bangla rendering

⛔ Ban — store Bangla digits as string
{
  "turbidityNtu": "৬.৮",
  "incidentCount": "১২"
}

// loses arithmetic;
// locale-tied at storage.
✓ OK — store number, render Bangla digits
{
  "turbidityNtu": 6.8,
  "incidentCount": 12
}

// --font-variant-numeric:
//   bengali renders ৬.৮
//   when locale = 'bn'.

9 · Bangla-aware Data Rules

Three rules from dim-4 §15 + dim-5 §10, restated as data-shape rules.

  1. Plain-text Bangla strings. Reporter messages, councillor names, ward names — plain string. Rendering swaps the font based on the container's data-locale.
  2. Bangla digits are presentation. Storage is JS number. font-variant-numeric: bengali renders Bangla digits in Bangla locale. Latin digits stay Latin; chained refs stay Latin even in Bangla locale.
  3. No per-string locale tags. Every locale-bearing field is a plain string. The locale is on <body>.

Live demo — same data, two locales

data-locale="en"
{
  "id": "anjali.b",
  "message": "Brown water since morning. Family of 4.",
  "ward": "ward-04",
  "timestamp": "2026-09-07T09:21:14Z"
}

Renders: "Brown water since morning. Family of 4." in Plex Sans.

data-locale="bn"
{
  "id": "anjali.b",
  "message": "সকাল থেকে পানি বাদামি। পরিবারে ৪ জন।",
  "ward": "ward-04",
  "timestamp": "2026-09-07T09:21:14Z"
}

Renders: "সকাল থেকে পানি বাদামি। পরিবারে ৪ জন।" in Noto Sans Bengali.

10 · Zod Schema Samples (optional)

If the team adopts Zod, each interface can be mirrored as a runtime validator. Zod is optional — TypeScript types are the source of truth.

import { z } from 'zod';

// Branded type via Zod
const SensorId = z.string().brand<'SensorId'>();

// Discriminated union enums
const BandSchema = z.enum(['high', 'medium', 'low']);
const ButtonVariantSchema = z.enum([
  'primary', 'secondary', 'ghost', 'danger'
]);

const ButtonPropsSchema = z.object({
  label: z.string().min(1),
  onClick: z.function(),
  variant: ButtonVariantSchema.default('primary'),
  size: z.enum(['sm', 'md', 'lg']).default('md'),
  icon: IconNameSchema.optional(),
  disabled: z.boolean().default(false),
});

// Runtime parse → throws on bad data;
// or use safeParse for structured failure.
const result = ButtonPropsSchema.safeParse(apiPayload);
